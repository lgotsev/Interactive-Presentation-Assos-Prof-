НАЙ-ЛЕСНО СТАРТИРАНЕ ВЪВ FIREFOX
1. Разархивирайте ЦЕЛИЯ ZIP в отделна папка.
2. Отворете index.html с двойно щракване.
3. Не отделяйте index.html от папката slides: слайдовите изображения се зареждат от нея.
4. Начало → Презентация / Експериментални изследвания / Научна дискусия.
5. В научния анализ използвайте раздели 01–04; In-domain / Zero-shot са режими на оценяване.
