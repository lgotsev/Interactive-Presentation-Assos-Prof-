# Hybrid QML Research Explorer — Next.js source

Тази версия използва **същия одобрен интерактивен HTML интерфейс**, който е тестван от автора в Firefox. Не пренаписва или подменя визуализациите: отваря ги локално чрез `/viewer/index.html` в iframe.

Изисквания: Node.js 20 или по-нова версия и достъп до npm при първото инсталиране.

```
npm install
npm run dev
```

След това отворете http://localhost:3000.

За статична компилация:

```
npm run build
```

В `out/` се получава статичен сайт, ако компилацията е успешна. Настройката `output: 'export'` е включена. Не е необходим API или база данни.

**Забележка:** Научният анализ е интегриран като проверен статичен интерактивен HTML ресурс, а не пренаписан като индивидуални React компоненти.
